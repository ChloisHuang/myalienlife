# 环境经历与居民差异

当前只扩展露米纳星湾和童梦星屿。旧种族、遗传和已获得的祈祷觉醒不回收；新的环境印记独立于种族，不是人人必经的升级终点。

## 三层状态

| 层次 | 状态 | 获得和消退 |
| --- | --- | --- |
| 短期反应 | 不安、花园活性 | 森林、同伴和附近植物改变反应；离开后逐步恢复或耗尽 |
| 长期适应 | 花园适应、森林适应 | 每个游戏日每条路线最多增长一次；个人兴趣决定上限，两项合计不超过 100；超过两天不再实践，每日减少 6 |
| 永久印记 | 花契、守影、根誓 | 一人只留一种，必须来自持续实践和一次具体的共同经历，不靠挂机或重复刷点击 |

花园上限为 `min(85, 35 + round(园艺偏好 * 1.5))`；森林上限由观察、探索偏好决定，幽冥族另有 15 点适应优势。普通叶芽和花朵受适应与活性共同控制；离开环境后会收拢、消退。永久花契保留花朵，守影保留淡淡的自主影子，根誓保留金色触角晶芽。头像也显示这些身体变化。

## 稀有共同经历

连续实践按不同游戏日计算，中断一天后重新计连续天数，最多记录 7 天。印记容量为存活居民数的八分之一向下取整，最少一个；人数减少不撤销已有印记，但不会继续新增超过容量的印记。

- **花契**：至少连续五天园艺、花园适应至少 55；接手不是自己照料到衰弱的花圃，将健康从不超过 25 恢复到至少 70，且有信任至少 15 的同伴在场。活性在异地消耗较慢，附近植物的恢复更强。
- **守影**：至少连续五天森林经历、森林适应至少 55；自己不安不超过 20 时完成对另一位不安至少 60、信任至少 20 的居民的陪伴或曦光安抚。觉醒耗费额外体力；以后即使普通适应退去，仍能成为森林中的安定同伴。
- **根誓**：已有曦灵或幽冥觉醒、至少连续五天照料圣树；接手活力低于 25 的衰弱圣树并恢复到至少 80，且有两位信任至少 15 的同伴在场。驻留圣树附近时加快其活力恢复。

花圃或圣树只临时记录一名危机照料者，不保存抢救过程日志。自己长期照料后任其衰弱，不能算作接手他人的危机。作物收获、重新种植和移除都会清理未完成的抢救记录。

## 关系与行动

信任、依赖、怨气是方向性的：可以依赖一个人，同时对他不满。照料、共同休息、森林互助和过度索取圣树会改变关系。陪伴候选现在由较安定者选择需要帮助的居民，而不是害怕的人反过来安抚旁人。关系会影响交谈、合作和出行候选；表达不满、道歉修复需要真实存在的隔阂。

## 存档与传输

- `src/living-state.js`：唯一存档模型与校验、v1 到 v2 的显式迁移、死者及移除场所清理。
- `src/living-adaptation.js`：适应上限、每日实践、消退、稀有印记与展示摘要。
- `src/living-world.js`：实际完成的行动、十游戏分钟一次的脉冲、环境和同伴影响。
- `src/living-visuals.js`：纯客户端外观和动画，不写存档、不传逐帧变换。

主存档仍为 v23，环境子结构为 v2。每人最多六条重要关系、三个固定大小的实践记录和一个印记枚举；每个实际场所只有固定字段，不新增事件数组或无限历史。迁移不虚构实践或授予印记；旧双适应超过 100 时按比例收敛到共同预算，原有种族保持不变。

压力测试使用超出目前两岛常规人口的 128 位居民、256 个场所，连续执行 144 次脉冲并逐次应用 JSON Patch 验证一致性。一次本地运行测得新增环境存档 87,114 字节，最大单次环境增量 29,459 字节，测试全流程约 1.7 秒。压缩对照为 1,362 字节，但这不是对线上 WebSocket 已启用压缩的承诺。数字仅包括环境系统，不代表整个游戏存档或网络负载。

## 验证

```sh
node --test tests/living-adaptation.test.js tests/living-world.test.js tests/living-visuals.test.js tests/living-capacity.test.js
ORBIT_TEST_URL=http://127.0.0.1:5173 npx playwright test --config playwright.living.config.js
```

新增其他岛屿时应在现有作用域、行动和表现模块内扩展规则，不追加按帧历史。增加新的持久字段必须升级环境子结构，并补充迁移、清理、尺寸和增量测试。
